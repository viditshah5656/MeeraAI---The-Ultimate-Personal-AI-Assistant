# Meera Desktop Frontend

## Required
Keep the extracted files together.
Start the backend before launching the desktop frontend.

## Run
Terminal 1:
```powershell
python Meera.py --api --port 8000
```

Terminal 2:
```powershell
cd desktop_frontend
npm install
npm run dev
```

## Build And Package
```powershell
cd desktop_frontend
npm install
npm run build
npm run package
npm run dist
```
