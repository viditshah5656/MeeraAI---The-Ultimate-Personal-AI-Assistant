### 📐 Mathematical Formulations & Rigorous Derivations

### 1. Unified Gradient Dynamics in Function Space

Let $\mathcal{D} = \{(x_i, y_i)\}_{i=1}^D \subset \mathcal{X} \times \mathbb{R}$ denote a training dataset sampled i.i.d. from a distribution $p(x, y)$. Consider a parameter vector $\Theta(t) \in \mathbb{R}^P$ evolving under continuous-time gradient descent on an empirical loss functional:

$$\mathcal{L}(\Theta) = \frac{1}{D} \sum_{i=1}^D \ell\left(f(x_i; \Theta), y_i\right)$$

The continuous-time parameter trajectory obeys the ordinary differential equation (ODE):

$$\frac{d\Theta(t)}{dt} = -\eta \nabla_\Theta \mathcal{L}(\Theta(t)) = -\frac{\eta}{D} \sum_{i=1}^D \nabla_\Theta f(x_i; \Theta(t)) \, \ell'\left(f(x_i; \Theta(t)), y_i\right)$$

where $\eta > 0$ is the learning rate and $\ell'(\hat{y}, y) = \frac{\partial \ell(\hat{y}, y)}{\partial \hat{y}}$. Apply the chain rule to determine the temporal evolution of the network prediction $f(x; \Theta(t))$ for an arbitrary test point $x \in \mathcal{X}$:

$$\frac{\partial f(x; \Theta(t))}{\partial t} = \left\langle \nabla_\Theta f(x; \Theta(t)), \frac{d\Theta(t)}{dt} \right\rangle_{\mathbb{R}^P}$$

Substituting the expression for $\frac{d\Theta(t)}{dt}$:

$$\frac{\partial f(x; \Theta(t))}{\partial t} = -\frac{\eta}{D} \sum_{i=1}^D \left\langle \nabla_\Theta f(x; \Theta(t)), \nabla_\Theta f(x_i; \Theta(t)) \right\rangle_{\mathbb{R}^P} \ell'\left(f(x_i; \Theta(t)), y_i\right)$$

Define the **Empirical Neural Tangent Kernel (NTK)** $K_t: \mathcal{X} \times \mathcal{X} \to \mathbb{R}$ at time $t$ as [Jacot et al. (2018)](https://arxiv.org/abs/1806.07572):

$$K_t(x, x') \triangleq \left\langle \nabla_\Theta f(x; \Theta(t)), \nabla_\Theta f(x'; \Theta(t)) \right\rangle_{\mathbb{R}^P} = \sum_{j=1}^P \frac{\partial f(x; \Theta(t))}{\partial \Theta_j} \frac{\partial f(x'; \Theta(t))}{\partial \Theta_j}$$

The exact functional governing dynamic equation simplifies to:

$$\frac{\partial f(x; \Theta(t))}{\partial t} = -\frac{\eta}{D} \sum_{i=1}^D K_t(x, x_i) \, \ell'\left(f(x_i; \Theta(t)), y_i\right)$$

### 2. Derivation of Infinite-Width Lazy Training Dynamics

Under standard parameterization (NTP) for an $L$-layer fully connected network $f(x; \Theta) = a_L(x)$, with activations $g_l(x) = \sigma(a_l(x))$ and pre-activations $a_l(x) = \frac{1}{\sqrt{N_{l-1}}} W_l g_{l-1}(x) + b_l$:

As the width of hidden layers $N_1, N_2, \dots, N_{L-1} \to \infty$, the parameter shift $\Delta \Theta(t) = \Theta(t) - \Theta(0)$ satisfies:

$$\|\Delta \Theta(t)\|_2 = \mathcal{O}(1), \quad \text{while} \quad \|\Theta(0)\|_2 = \mathcal{O}(\sqrt{P})$$

Consequently, a first-order Taylor expansion around initialization $\Theta_0 \triangleq \Theta(0)$ becomes exact in function space:

$$f(x; \Theta(t)) = f(x; \Theta_0) + \left\langle \nabla_\Theta f(x; \Theta_0), \Theta(t) - \Theta_0 \right\rangle_{\mathbb{R}^P} + \mathcal{O}\left(\|\Theta(t) - \Theta_0\|_2^2\right)$$

In this limit, $K_t(x, x') = K_0(x, x') = K^*_\infty(x, x')$ remains completely time-invariant.

#### Closed-Form Solution for Mean Squared Error (MSE)
For $\ell(\hat{y}, y) = \frac{1}{2}(\hat{y} - y)^2$, let $\mathbf{y} = [y_1, \dots, y_D]^\top \in \mathbb{R}^D$ and $\mathbf{f}_t = [f(x_1; \Theta(t)), \dots, f(x_D; \Theta(t))]^\top \in \mathbb{R}^D$. Defining the Gram matrix $\mathbf{\Phi}_0 \in \mathbb{R}^{D \times D}$ as $(\mathbf{\Phi}_0)_{ij} = K^*_\infty(x_i, x_j)$, the system of linear differential equations is:

$$\frac{d\mathbf{f}_t}{dt} = -\frac{\eta}{D} \mathbf{\Phi}_0 \left(\mathbf{f}_t - \mathbf{y}\right)$$

Solving via the matrix exponential:

$$\mathbf{f}_t = \mathbf{y} + \exp\left( -\frac{\eta}{D} \mathbf{\Phi}_0 t \right) \left( \mathbf{f}_0 - \mathbf{y} \right)$$

For an unobserved test point $x^*$, the out-of-sample prediction is:

$$f(x^*; \Theta(t)) = f(x^*; \Theta_0) + \mathbf{k}(x^*)^\top \mathbf{\Phi}_0^{-1} \left( \mathbf{I}_D - \exp\left( -\frac{\eta}{D} \mathbf{\Phi}_0 t \right) \right) \left( \mathbf{y} - \mathbf{f}_0 \right)$$

where $\mathbf{k}(x^*) = [K^*_\infty(x^*, x_1), \dots, K^*_\infty(x^*, x_D)]^\top \in \mathbb{R}^D$. As $t \to \infty$, $\exp\left( -\frac{\eta}{D} \mathbf{\Phi}_0 t \right) \to \mathbf{0}$, recovering the exact ridgeless Kernel Ridge Regression (KRR) solution [Jacot et al. (2018)](https://arxiv.org/abs/1806.07572):

$$\lim_{t \to \infty} f(x^*; \Theta(t)) = f(x^*; \Theta_0) + \mathbf{k}(x^*)^\top \mathbf{\Phi}_0^{-1} (\mathbf{y} - \mathbf{f}_0)$$

### 3. Maximal Update Parameterization ($\mu P$) and Feature Evolution

To avoid the static-kernel lazy regime and enforce non-trivial feature learning ($dK_t/dt = \Theta(1)$), parameter updates across all layers must scale identically with respect to width $N$. 

| Parameterization Scheme | Weight Initialization $W_l \sim \mathcal{N}(0, \sigma_0^2)$ | Forward Scale Factor | Learning Rate Scaling $\eta_l$ | NTK Variance $\Delta K_t$ |
| :--- | :--- | :--- | :--- | :--- |
| **Standard (NTP)** | $\sigma_0^2 = 1$ | $1/\sqrt{N}$ | $\eta = \Theta(1)$ | $\mathcal{O}(1/N)$ (Lazy) |
| **Standard PyTorch** | $\sigma_0^2 = 1/N$ | $1$ | $\eta = \Theta(1)$ | Unstable / Explosion |
| **Maximal Update ($\mu P$)** | $\sigma_0^2 = 1/N$ | $1/\sqrt{N}$ | $\eta_l = \Theta(1/N)$ | $\Theta(1)$ (Rich Regime) |

Under $\mu P$, hidden layer pre-activations scale as $a_l(x) = \frac{1}{N} W_l g_{l-1}(x)$, with parameter updates $\Delta W_l = \Theta(1)$. The spectral norm of the change in kernel values satisfies:

$$\|K_t - K_0\|_{op} = \Theta(1)$$

allowing the representation coordinates to dynamically align with the principal components of the target data distribution.

### 🔬 Formal Theorems & Analytic Proofs

### Theorem 1 (Existence, Uniqueness, and Uniform Convergence of the Infinite-Width NTK)
*Let $f(x; \Theta)$ be a fully connected network of depth $L$ with Lipschitz-continuous activations $\sigma$ satisfying $|\sigma(x)| \le C(1 + |x|)$. Let parameters be initialized as $\Theta_0 \sim \mathcal{N}(0, \mathbf{I})$. As hidden layer widths $N_1, N_2, \dots, N_{L-1} \to \infty$ sequentially or simultaneously, the empirical kernel $K^{(L)}_0(x, x')$ converges in probability to a deterministic limit kernel $K^*_{(L)}(x, x')$ uniformly over any compact subset $\mathcal{K} \subset \mathcal{X} \times \mathcal{X}$ [Jacot et al. (2018)](https://arxiv.org/abs/1806.07572):*

$$\lim_{\min(N_l) \to \infty} P\left( \sup_{x, x' \in \mathcal{K}} \left| K^{(L)}_0(x, x') - K^*_{(L)}(x, x') \right| \ge \epsilon \right) = 0, \quad \forall \epsilon > 0$$

#### Formal Proof Strategy
1. Define the recurrence relation for the covariance operator (Neural Network Gaussian Process kernel $K_{NNGP}^{(l)}$) at layer $l$:
   $$\Sigma^{(1)}(x, x') = \frac{1}{d_{in}} x^\top x' + b_0^2$$
   $$\Sigma^{(l+1)}(x, x') = \sigma_\omega^2 \mathbb{E}_{(u, v) \sim \mathcal{N}(0, \mathbf{\Lambda}^{(l)})} \left[ \sigma(u)\sigma(v) \right] + \sigma_b^2$$
   where $\mathbf{\Lambda}^{(l)} = \begin{pmatrix} \Sigma^{(l)}(x, x) & \Sigma^{(l)}(x, x') \\ \Sigma^{(l)}(x', x) & \Sigma^{(l)}(x', x') \end{pmatrix}$.

2. By the Strong Law of Large Numbers (SLLN) and the Multidimensional Central Limit Theorem, as $N_l \to \infty$, the pre-activations $a_l(x)$ conditionally converge to a Gaussian process $\mathcal{GP}(0, \Sigma^{(l)})$.

3. Express the recursive derivation of the NTK $K^*_{(l)}(x, x')$:
   $$\dot{\Sigma}^{(l+1)}(x, x') = \sigma_\omega^2 \mathbb{E}_{(u, v) \sim \mathcal{N}(0, \mathbf{\Lambda}^{(l)})} \left[ \sigma'(u)\sigma'(v) \right]$$
   $$K^*_{(l+1)}(x, x') = K^*_{(l)}(x, x') \, \dot{\Sigma}^{(l+1)}(x, x') + \Sigma^{(l+1)}(x, x')$$

4. Application of concentration inequalities (specifically McDiarmid's inequality and uniform bound tightness via Rademacher complexity over $\mathcal{K}$) yields the uniform bound, completing the proof $\blacksquare$.

### Theorem 2 (Exponential Dynamic Spectral Convergence on Finite Datasets)
*Assume the limiting NTK Gram matrix $\mathbf{\Phi}_0 \in \mathbb{R}^{D \times D}$ on a finite dataset $\mathcal{D}$ is strictly positive definite, with minimum eigenvalue $\lambda_{\min} > 0$. Under continuous-time NTK dynamics with MSE loss, the empirical training loss $\mathcal{L}(t)$ decays exponentially to zero:*

$$\mathcal{L}(t) \le \mathcal{L}(0) \, \exp\left( -\frac{2 \eta \lambda_{\min}}{D} t \right)$$

#### Formal Proof
The training loss is given by $\mathcal{L}(t) = \frac{1}{2D} \|\mathbf{f}_t - \mathbf{y}\|_2^2$. Differentiating with respect to $t$:

$$\frac{d\mathcal{L}(t)}{dt} = \frac{1}{D} (\mathbf{f}_t - \mathbf{y})^\top \frac{d\mathbf{f}_t}{dt}$$

Substitute $\frac{d\mathbf{f}_t}{dt} = -\frac{\eta}{D} \mathbf{\Phi}_0 (\mathbf{f}_t - \mathbf{y})$ into the derivative:

$$\frac{d\mathcal{L}(t)}{dt} = -\frac{\eta}{D^2} (\mathbf{f}_t - \mathbf{y})^\top \mathbf{\Phi}_0 (\mathbf{f}_t - \mathbf{y})$$

By Rayleigh's quotient inequality, for any vector $\mathbf{v} \in \mathbb{R}^D$:

$$\mathbf{v}^\top \mathbf{\Phi}_0 \mathbf{v} \ge \lambda_{\min}(\mathbf{\Phi}_0) \|\mathbf{v}\|_2^2$$

Substituting $\mathbf{v} = \mathbf{f}_t - \mathbf{y}$:

$$\frac{d\mathcal{L}(t)}{dt} \le -\frac{\eta \lambda_{\min}}{D^2} \|\mathbf{f}_t - \mathbf{y}\|_2^2 = -\frac{2 \eta \lambda_{\min}}{D} \left( \frac{1}{2D} \|\mathbf{f}_t - \mathbf{y}\|_2^2 \right) = -\frac{2 \eta \lambda_{\min}}{D} \mathcal{L}(t)$$

Applying Grönwall's Lemma to this differential inequality yields:

$$\mathcal{L}(t) \le \mathcal{L}(0) \exp\left( -\frac{2 \eta \lambda_{\min}}{D} t \right)$$

This guarantees global linear convergence (exponential decay) to zero global training loss $\blacksquare$.

### Theorem 3 (Asymptotic Power-Law Generalization Bounds)
*Let the Mercer expansion of the infinite-width kernel be $K(x, x') = \sum_{k=1}^\infty \mu_k \phi_k(x) \phi_k(x')$, where $\mu_k \propto k^{-\alpha}$ with decay power $\alpha > 1$. Let the target function $f^*(x) = \sum_{k=1}^\infty w_k^* \phi_k(x)$ satisfy the capacity condition $\sum_{k=1}^\infty \frac{(w_k^*)^2}{\mu_k^r} < \infty$ for $r \in (0, 1]$. Then, the expected generalization risk $\mathcal{R}(D)$ under ridgeless kernel regression scales asymptotically with sample size $D$ as [Bordelon et al. (2024)](https://arxiv.org/abs/2402.01092):*

$$\mathcal{R}(D) \sim \mathcal{O}\left( D^{-\beta} \right), \quad \text{where} \quad \beta = \min\left(1, \, r(\alpha - 1)\right)$$

#### Formal Proof Sketch
1. The generalization risk can be decomposed via the continuous operator spectrum as:
   $$\mathcal{R}(D) = \sum_{k=1}^\infty (w_k^*)^2 \left( 1 - \frac{\mu_k}{\mu_k + \lambda(D)} \right)^2$$
   where $\lambda(D)$ is the effective regularization parameter satisfying the implicit self-consistency condition $\lambda(D) = \frac{1}{D} \sum_{k=1}^\infty \frac{\mu_k \lambda(D)}{\mu_k + \lambda(D)}$.

2. Converting the discrete sum to an integral using $\mu_k \sim k^{-\alpha}$:
   $$\sum_{k=1}^\infty \frac{k^{-\alpha}}{k^{-\alpha} + \lambda} \approx \int_{1}^\infty \frac{x^{-\alpha}}{x^{-\alpha} + \lambda} dx \sim \lambda^{-1/\alpha}$$

3. Equating $D \lambda^{1/\alpha} \sim 1 \implies \lambda(D) \sim D^{-\alpha}$. Substituting $\lambda(D)$ into the risk integral with $w_k^* \sim k^{-\frac{r \alpha + 1}{2}}$ produces the exact exponent $\beta = r(\alpha - 1)$ $\blacksquare$.

### 🛑 Critical Bottlenecks & Theoretical Limits

### 1. Thermodynamic Ceilings & Compute Scaling Limits

The energy consumption per FLOP during training and inference poses physical constraints. Landauer's Principle establishes the minimum energy required to erase or process one bit of information:

$$E_{\text{min}} = k_B T \ln 2$$

Where $k_B$ is the Boltzmann constant ($1.380649 \times 10^{-23} \text{ J/K}$) and $T$ is the absolute temperature in Kelvin (~300 K). Thus, $E_{\text{min}} \approx 2.87 \times 10^{-21} \text{ Joules per bit operation}$.

Modern CMOS hardware operates around $10^{-11} \text{ J/FLOP}$ ($10 \text{ pJ/FLOP}$), leaving a gap of roughly eight orders of magnitude from theoretical thermodynamic limits. Compute scaling encounters severe thermal design power (TDP) walls at the megawatt and gigawatt cluster scales.

```
       10^-11 J/FLOP ───► [ Modern Sub-3nm CMOS Chips ]
                                   │
                                   │  ~10^8 Energy Inefficiency Gap
                                   ▼
       10^-21 J/Bit  ───► [ Landauer's Thermodynamic Floor ]
```

### 2. The Memory Wall & Communication Bottlenecks

In Mixtral and MoE architectures, parameter growth scales capacity without linear increases in compute per token ($FLOPs/token$). However, execution is bound by memory bandwidth:

$$\text{Operational Intensity } (\Phi) = \frac{\text{Total Floating-Point Operations (FLOPs)}}{\text{Total Memory Access Bytes (Bytes)}}$$

When $\Phi < \frac{\text{Peak Compute Performance (FLOP/s)}}{\text{Memory Bandwidth (Bytes/s)}}$, execution is memory bandwidth-bound. 

For an autoregressive generation step with $P$ active parameters stored in High Bandwidth Memory (HBM3e/HBM4) at 16-bit precision ($2P$ bytes), generating $1$ token requires transferring $2P$ bytes.

If $P = 220 \times 10^9$ parameters:

$$\text{Data Transfer} = 220 \times 10^9 \times 2 \text{ bytes} = 440 \text{ GB per token}$$

For an HBM bandwidth $B = 4.8 \text{ TB/s}$, maximum single-batch token generation rate $R_{\text{max}}$ is:

$$R_{\text{max}} = \frac{4.8 \times 10^{12} \text{ Bytes/s}}{4.4 \times 10^{11} \text{ Bytes/token}} \approx 10.9 \text{ tokens/second}$$

Batching improves arithmetic intensity, but context length scaling introduces memory overhead through KV-cache growth:

$$\text{Memory}_{\text{KV}} = 2 \times b \times L \times n_{\text{layers}} \times d_{\text{head}} \times n_{\text{heads}} \times S_{\text{bytes}}$$

Where $b$ is batch size, $L$ is sequence length, and $S_{\text{bytes}}$ is precision size. As $L \to 10^7$ tokens, KV-cache management requires aggressive quantization (e.g., FP4/INT4 KV-caches) or state-space/linear-attention alternatives.

### 3. Data Exhaustion & Scaling Law Saturation

According to Chinchilla scaling laws ([Hoffmann et al., 2022](https://arxiv.org/abs/2203.15556)), optimal parameter count $N$ and token count $D$ follow:

$$N_{\text{opt}} \propto C^{a}, \quad D_{\text{opt}} \propto C^{b}$$

Where $a \approx 0.5$, $b \approx 0.5$, and $C$ represents total training compute budget in FLOPs ($C \approx 6ND$). 

```
  Compute (C) ───►  N ∝ C^0.5  (Parameters)
              └───►  D ∝ C^0.5  (High-Quality Tokens)
```

Human-generated web text is finite ($\sim 10^{14}$ to $10^{15}$ tokens of high quality). Training models beyond $C \approx 10^{26} \text{ FLOPs}$ requires synthetic data generation. However, naive iterative training on synthetic distributions leads to model collapse—a structural breakdown where probability distribution variance shrinks:

$$\lim_{t \to \infty} \mathbb{D}_{\text{KL}}\left(P_{\text{true}} \parallel P_{t}\right) = \infty$$

Mitigating collapse requires strict verification filters, rejection sampling, and reward modeling at data generation time.

### 4. Mathematical Limits of Inference-Time Scaling

Inference scaling relies on searching reasoning paths at test-time ([Brown et al., 2024](https://arxiv.org/abs/2408.03314)). Let $N_{\text{test}}$ be the test-time compute allocated per query. The error probability $P(\text{Error})$ decays as a power law until hitting a saturation plateau set by the model's policy generator:

$$P(\text{Error} \mid N_{\text{test}}) = \alpha \cdot N_{\text{test}}^{-\gamma} + \epsilon_{\text{intrinsic}}$$

```
   P(Error)
      │
  1.0 ┼───\
      │    \  Power-Law Decay (N_test ^ -γ)
      │     \
  0.1 ┼───────\─────────────────────────── Plateau (ε_intrinsic)
      │        \__________________________
      └─────────────────────────────────────► Test-Time Compute (N_test)
```

Where $\gamma$ is the search efficiency coefficient, and $\epsilon_{\text{intrinsic}}$ represents unrecoverable error due to search-space misalignments or systematic Process Reward Model (PRM) hallucinations.
